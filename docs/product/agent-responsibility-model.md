# 系统 Agent、应用 Agent 与 UI 职责模型

修订日期：2026-08-02  
状态：V0.3 产品架构基线

## 核心修正

小艺不是应用内学习 Agent 的远程 UI，A2A Task 也不是应用全部业务状态的唯一来源。正确关系是：小艺作为系统 Agent 负责理解跨应用意图、承载系统 UI、代理应用无法直接完成的系统能力，并在合适时把用户交接给应用；应用内 Agent 独立负责学习业务的持续演进。

```text
用户
 ├─ 小艺系统 Agent
 │   ├─ 系统意图识别与应用发现
 │   ├─ 系统 UI / 对话 / 卡片 / 确认
 │   ├─ 系统能力代理（计划、提醒等，具体能力待设备确认）
 │   └─ A2A Adapter ↔ 应用公开 Agent 能力
 │
 └─ 回声词伴 App
     ├─ App UI：高密度学习交互
     ├─ App Agent：教学策略、解释、个性化与业务编排
     ├─ Domain：词库、学习证据、复习计划与状态机
     └─ Data：用户长期学习记忆
```

## 四个角色

### 1. 小艺系统 Agent

负责：

- 从自然语言识别“要找哪个应用、完成什么系统或跨应用目标”。
- 在系统侧展示确认、结果、进度或后续入口；应用只提供语义数据，不能假装控制系统 UI 的具体布局。
- 在用户授权后代理系统级能力，例如计划、提醒或系统入口；具体可用能力及报文必须以目标设备为准。
- 发现应用公开的 AgentCard/Skill，建立 A2A 连接，或把用户引导到应用。

不负责：

- 决定每个单词的教学策略。
- 维护完整的用户学习画像。
- 替代应用内高密度答题、提示、解释与复盘体验。

### 2. A2A Adapter（应用公开 Agent 边界）

当前由 `WordReviewAgentAbility` 承担。它不是完整应用 Agent，只负责：

- 把系统 Agent 的 RequestContext、文本和 metadata 归一化为公开产品意图。
- 判断本次通信是系统侧完成、应用交接、系统能力委托，还是需要保持最小任务投影。
- 把 App Agent 的语义结果翻译为 TaskStatus、Message 和 Artifact。
- 管理连接、认证、取消、错误、幂等和可观测日志。

它不应直接包含三词教学流程、个性化策略或完整学习状态机。

### 3. 应用内 App Agent

负责应用内长期竞争力：

- 根据到期队列、历史错误和用户目标创建学习计划。
- 决定何时提问、提示、解释、生成迁移题或调整难度。
- 调用应用内部工具与模型，维护个性化记忆和可解释学习证据。
- 在用户进入应用后独立运行；是否继续与小艺通信取决于是否仍需要系统 UI 或系统能力。
- 随产品迭代独立进化，不把小艺的对话状态当作自身智能来源。

### 4. App UI

负责：

- 主动回忆、提示、选词、输入、对比、复盘等高密度交互。
- 展示 App Agent 的教学决策和理由。
- 接收小艺交接的公开意图与实体，再由 App Agent 创建或恢复本地学习会话。

App UI 不绘制“小艺系统伴随卡”的伪造版本。原型可以并排展示两个真实边界，但必须明确系统侧画面只是系统行为示意，应用不能控制其视觉细节。

## 本机 SDK 能力边界

本机 HarmonyOS API 26 声明显示：

- A2A Server 提供 `updateStatus()`、`addArtifact()`、Task/Message/metadata 与 operation 回调。
- `AgentExtensionContext` 继承普通 `ExtensionContext`，只新增 `agentCard`；声明中没有 `startAbility()`。
- 标准 A2A API 没有“跳转应用”方法。
- AgentCard 的 `appInfo` 包含 bundle/module/ability，系统可以据此识别应用，但实际交接触发、Want 内容与系统 UI 行为仍需设备证据。
- `AgentUIExtensionAbility` 是可选的应用富 UI 承载形式，不等于应用可以控制小艺原生系统 UI。

因此，当前工程不能把 `TaskState.INPUT_REQUIRED` 或 Artifact 当作“已经实现拉起应用”的证据。

## 数据所有权

| 数据 | 权威拥有者 |
|---|---|
| 小艺对话与系统 UI 状态 | 小艺系统 Agent |
| 系统计划/提醒 ID 与授权状态 | 系统能力提供方 |
| A2A 连接、TaskStatus 与协议关联 ID | A2A Adapter |
| 当前学习题、提示层级、作答证据 | App Agent / Domain |
| 长期词汇掌握、混淆模式与个性化 | App Data |
| 系统侧展示的学习进度 | App Agent 产生的最小只读投影 |

系统投影可以过期或断开，但不能反向覆盖 App Agent 的长期学习事实。

## 设计不变量

- A2A operation 不等于产品意图；`EXECUTE` 只表示协议动作。
- AgentCard Skill 不等于应用内工具；只公开需要系统 Agent 协作的能力。
- 拉起应用后默认不维持长连接；只有仍需系统 UI、系统计划或跨界面控制时才继续。
- 小艺侧只拿完成当前系统目标所需的最少学习数据。
- App Agent 可以在没有小艺连接时完整完成学习流程。
- “同一任务”指业务上可关联，不要求小艺 Task 成为应用内部所有状态的主键。
