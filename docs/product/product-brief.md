# 产品简报：回声词伴

## 一句话

一个先保护回忆、再提供恰到好处帮助的 AI 单词陪练；应用内 Agent 独立完成高密度学习，小艺负责系统入口、短结果和用户明确需要的系统能力协作。

## 用户问题

传统背词产品常在两个极端之间摇摆：要么只是卡片和打分，理解不够；要么让 AI 过早解释和聊天，用户看懂了却没有真正记住。我们要解决的是“从背到理解”的跃迁，同时不牺牲主动提取效果。

## 核心循环

```text
小艺交接或用户直接进入 App
  → App Agent 创建/恢复学习会话
  → 主动回忆
  → 用户自评/作答
  → 按需分级提示（每层提示后再次回忆，不同步揭示答案）
  → AI 针对错误做短解释或对比
  → 一个微型迁移题
  → 形成可复习的任务产物
  → 安排下一次间隔复习
```

## 首版场景

三个公开能力的入口、系统协作状态与 Artifact 见 [公开 Skill 契约](skill-contracts.md)；应用内学习不变量由 App Agent 领域模型负责。

### 1. 今日抽背

目标：在 3–5 分钟内复习 5–10 个到期或易错词。  
主界面：单词、简短任务、三档自评、提示入口。  
AI 介入点：用户模糊/不会、连续混淆、主动追问。

### 2. 深度理解

目标：解释一个具体误区，例如 `resilient` 与 `resistant` 的区别。  
主界面：对比、最小充分解释、情境选择。  
AI 介入点：根据用户刚才的错误生成解释，不做百科全书式展开。

交互顺序：先给一个新的情境让用户判断，再展示最小充分解释；不能把“看懂解释”误记为“已经会用”。

### 3. 小艺入口与系统协作

目标：用户从小艺说“陪我复习十个易错词”后进入应用；小艺也可以承载一次快速辨析结果，或在用户授权后代理提醒等系统能力。  
系统 UI：意图确认、短结果、应用入口、系统计划确认，以及显式伴随时的最小进度。  
应用 UI：具体题目、提示、解释、复盘和个性化。  
连接策略：进入应用后默认结束 A2A；只有仍需系统 UI、系统计划或跨界面控制时才维持。

## 设计原则

1. 学习优先：先保护主动提取，再优化流畅感。
2. AI 后置：AI 是困难出现后的脚手架，不是每题常驻讲解员。
3. 短反馈：默认反馈一句话能说清；需要时再展开。
4. 状态透明：用户始终知道任务在做什么、为什么暂停、如何继续。
5. 权威分层：App Agent 拥有学习事实；小艺只显示完成当前系统目的所需的最小投影。
6. 情感克制：提供陪伴感，但不靠夸张激励、虚假人格关系或打断学习的闲聊。
7. 数据可解释：呈现提示依赖、混淆词和复习依据，而不是神秘的“AI 掌握度”。

## 交互不变量

- 用户选择“需要提示”或“完全卡住”时，第一步只能出现提示，不能同时出现完整答案。
- 每层提示后都要给用户一次重新提取的机会；只有用户确认仍未想起，才进入下一层或答案。
- 一次作答只能生成一条结果记录，并带上实际使用的提示层级。
- 深度理解必须包含至少一个新的迁移情境，解释出现在判断之后。
- 从小艺交接到 App 时，应传递足够的公开意图和实体；App Agent 根据自身 session 恢复当前词、证据和提示层级，不能用 A2A Task 冒充完整学习会话。
- A2A 取消只结束系统协作；App 内暂停/放弃会话由 App Agent 按学习证据规则独立处理。

## 首版不做

- 不做通用英语聊天机器人。
- 不做完整课程体系或词书商城。
- 不用 AI 自动判定一切；首版保留用户自评并记录作答证据。
- 不把连续签到、排行榜作为核心价值。
- 不在未验证系统行为前设计依赖特定小艺动画或卡片样式的流程。

## 验证指标

- 任务完成率：开始后完成 5 个词的比例。
- 主动回忆率：未展开提示即作答的比例。
- 提示依赖：每个词平均提示层级及其随时间变化。
- 提示转化：提示 1 / 提示 2 后重新想起的比例，而不只是提示点击量。
- 延迟回忆：24 小时 / 7 天后正确率。
- 误区修复：近义词辨析微题的首次与复测表现。
- 恢复成功率：从后台或系统入口继续到原任务的比例。

## V0.2 原型结论与修订

- 今日抽背覆盖独立想起、提示后想起、两层提示后仍未想起和动态复盘。
- 深度理解覆盖 `INPUT_REQUIRED → COMPLETED`，且用户判断前解释不可见。
- 旧原型验证了应用内恢复到第 2 个词、提示 1/2 和完成 1/3 的学习不变量。
- 旧原型把系统伴随卡与应用学习过程绑定得过紧，容易误解为应用控制系统 UI；V0.3 将改为“小艺入口/短答/系统能力/显式伴随”四类边界展示。
- V0.3 已将 A2A `CANCELED` 与 App 会话暂停分离，系统协作取消不会删除学习事实。
